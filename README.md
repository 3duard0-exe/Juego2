Juego 2: Snake

Este repositorio contiene `snake.py`, un videojuego clásico de Snake desarrollado en Python utilizando la biblioteca Turtle Graphics de Free Python Games.
 El programa permite controlar una víbora que se desplaza por la ventana para recoger comida, aumentar su tamaño y evitar chocar consigo misma o salirse de los límites de la pantalla.

## Cambios realizados por mí

- Modifiqué el funcionamiento de la comida para que pueda desplazarse aleatoriamente un paso a la vez.
- Agregué una condición para evitar que la comida salga de los límites de la ventana del juego.

## Cambios realizados por mi compañero

- Agregó un sistema para asignar colores aleatorios a la víbora y a la comida cada vez que inicia el juego.
- Implementó una selección de colores de una lista de cinco opciones diferentes, excluyendo el color rojo.
- Aseguró que la víbora y la comida siempre tengan colores diferentes entre sí.

Estos cambios permiten incorporar mayor variedad visual al videojuego y agregar movimiento aleatorio a la comida,
haciendo que la experiencia de juego sea más dinámica.
